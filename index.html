EU Education Expenditure Dashboard

This dashboard displays education expenditure as a percentage of GDP for all 27 EU member states. Data is sourced from the World Bank API and shows historical trends from 1995-2023. The charts are generated using a loop to batch download data from the API and another loop to embed them dynamically.

Accessing data: Scraper and API.

USA Economic Indicators: GDP Growth & Treasury Yields

This chart displays three key USA economic indicators from 2000 to present, all pulled from live APIs: GDP Growth Rate (annual percentage from World Bank), 10-Year Treasury Yield (annual average from US Treasury), and 3-Month Treasury Bill Rate (annual average from US Treasury). All data is sourced directly from the World Bank and US Treasury Department APIs and updates automatically. No API keys required!

Interactive Globe: World Taxation Systems and Tax Rates

This interactive globe visualization displays taxation systems and tax rates for countries worldwide, scraped from Wikipedia using BeautifulSoup. The data includes taxation system types (Citizenship-based, Residential, Territorial, No income tax), corporate tax rates, individual income tax ranges, and VAT/GST/Sales tax rates. Use the rotation sliders to explore different regions, and hover over countries to see detailed tax information. Countries colored in royal blue use citizenship-based taxation (taxing citizens worldwide), while other colors represent different taxation approaches.

Hosting. Display charts in your own site.

Fertility Rate Vs. GDP per Capita in the UK

In this graph I combined two data series obtained through the World Bank API. Even though they were on different scales, I made sure that both axes were aligned so that, for example, the number 3 on the Fertility Rate axis corresponds to the number 30,000 on the GDP per Capita axis. I formatted the GDP per Capita numbers to use a "," as a thousands separator, including those in the tooltip.

Unemployment Rate in the UK Vs. in Other Countries

In this chart I plotted the same series obtained through the World Bank API for various countries. Given that the chart looks a bit crowded, I added the functionality to isolate a line by clicking on it using a condition inside the opacity property. Unfortunately, this functionality from VegaLite does not appear to function so well on a mobile browser.
